## Instructions for running the source code
All codes were developed and tested using an online Java compiler. To run the codes:
1. Open https://www.programiz.com/java-programming/online-compiler/
2. Open the required java file.
3. Copy and paste the code into the compiler.
4. Run the code.
5. Enter the prompted input.

No local Java installation is required to run the codes.
